# B0 需求与验收草案

## 业务目标

员工能够检索获授权的资料，并通过引用定位原文。
未获授权的主体无法通过检索或引用入口读取资料。

## 演示范围

- 使用一个演示租户和明确标注的合成资料。
- 支持 UTF-8 编码的 TXT 文本导入。
- 打通导入、授权检索、引用预览的纵向流程。
- 身份采用受控演示账号，由服务端识别当前主体。
- 多租户、PDF、混合检索和模型问答在 B1 逐项扩展。

## 演示角色

- 知识管理员：管理指定范围内的资料。
- 员工甲：被授予演示文档的阅读权限。
- 员工乙：未被授予该文档的阅读权限。

## 权限规则

1. 管理权限与文档阅读权限分别判断。
2. 管理员需要单独获得阅读授权，才能检索或预览正文。
3. 员工默认不能导入资料。
4. 检索和引用预览均由服务端校验权限。
5. 客户端修改主体、租户或文档标识，不能绕过授权。
6. 未获授权的资料不能进入检索响应。

## 正常业务流程

1. 知识管理员导入一份合成 TXT 文档。
2. 系统完成校验和处理，记录文档及版本。
3. 系统依据授权关系确定员工可访问的资料。
4. 员工甲输入问题，获得匹配片段及来源。
5. 员工甲打开引用，定位到对应版本的原文片段。

## 验收条件

| 编号 | 场景 | 预期结果 |
| --- | --- | --- |
| B0-01 | 管理员导入有效 TXT | 文档处理成功，产生可检索内容 |
| B0-02 | 员工导入资料 | 拒绝操作 |
| B0-03 | 导入空文本或格式不符的文件 | 明确失败，不产生可检索内容 |
| B0-04 | 员工甲检索文档中已有内容 | 返回匹配片段及来源 |
| B0-05 | 员工乙执行相同检索 | 不返回该受限文档的正文或来源信息 |
| B0-06 | 员工甲打开引用 | 定位到对应文档、版本与原文位置 |
| B0-07 | 员工乙直接请求该引用 | 拒绝访问且不返回原文 |
| B0-08 | 查询没有匹配资料的内容 | 明确显示无匹配结果 |
| B0-09 | 管理员未获阅读授权时检索正文 | 不返回该文档内容 |
